# 记忆力大考验 - 纸巾萝卜猫

一个精美的翻牌配对记忆游戏，具有5个难度关卡和完整的音效系统。

## 🎮 游戏特色

### 关卡设计
- **关卡1**: 2对卡牌 (2×2网格) - 初级挑战
- **关卡2**: 8对卡牌 (4×4网格) - 进阶训练  
- **关卡3**: 18对卡牌 (6×6网格) - 高级挑战
- **关卡4**: 32对卡牌 (8×8网格) - 专家级别
- **关卡5**: 50对卡牌 (10×10网格) - 大师挑战

### 音效系统
- 🔊 翻牌音效
- 🎵 匹配成功音效
- ❌ 匹配失败音效
- 🏆 游戏胜利音效
- 🔇 音效开关控制

### 技术特性
- 📱 响应式设计，支持移动端和桌面端
- 🎨 精美的UI界面和动画效果
- 🎯 10种不同的道具卡牌
- 📊 游戏统计和进度跟踪
- 🌐 纯前端实现，无需服务器

## 🚀 快速开始

### 在线游戏
直接访问：[记忆力大考验](https://your-username.github.io/memory-card-game)

### 本地运行
1. 克隆项目
```bash
git clone https://github.com/your-username/memory-card-game.git
cd memory-card-game
```

2. 启动本地服务器
```bash
# 使用Python
python -m http.server 8080

# 或使用Node.js
npx serve -p 8080
```

3. 打开浏览器访问 `http://localhost:8080`

## 🎯 游戏规则

1. **翻牌配对**: 点击卡牌翻开，寻找相同的道具进行配对
2. **记忆挑战**: 每次只能翻开2张卡牌，记住位置是关键  
3. **完成目标**: 配对完成所有卡牌即可通关胜利

## 🛠️ 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **音频**: Web Audio API
- **图形**: CSS动画和变换
- **兼容性**: 现代浏览器 (Chrome, Firefox, Safari, Edge)
